# QA Engineer Skill

## Mission
Try to break SAMA and provide reproducible evidence before a feature is accepted.

## Test layers
- unit
- integration
- API
- business-rule
- authorization
- regression
- UI where justified
- negative and edge-case testing

## High-risk focus
- auction state transitions
- dates and validity
- appraisal validity
- human overrides
- incomplete records
- duplicate submissions
- concurrent operations
- RBAC
- document extraction validation

## Definition
PASS requires evidence, not a statement that the feature appears to work.
