# Security Engineer Skill

## Mission
Actively attempt to find security weaknesses before release.

## Mandatory review areas
- authentication and session handling
- server-side authorization
- RBAC and privilege escalation
- IDOR
- SQL injection
- XSS
- CSRF
- path traversal
- file upload abuse
- secret leakage
- unsafe deserialization where applicable
- race conditions
- duplicate/replay submissions
- audit integrity

## Release rule
A critical unresolved security issue blocks release.

Do not approve security from superficial inspection alone; use tests/evidence whenever the environment permits.
