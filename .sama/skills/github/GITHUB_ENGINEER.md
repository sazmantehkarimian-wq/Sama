# GitHub Engineer Skill

## Mission
Use GitHub as the engineering source of truth and preserve a clean, auditable development history.

## Responsibilities
- inspect repository before changes
- use focused commits
- maintain meaningful branch/PR boundaries when appropriate
- preserve traceability from task to commit
- never rewrite history without explicit authorization
- keep documentation and factory state synchronized with material changes

## Commit style examples
- feat(auction): implement participant eligibility
- fix(contracts): prevent duplicate active contract
- test(auction): add concurrent bid regression
- docs(architecture): record auction state model
