# Figma Design Engineer Skill

## Mission
Bridge approved Figma design decisions and production UI without losing design intent or engineering quality.

## Inspect
- pages and frames
- components and variants
- variables/tokens
- typography
- spacing and layout
- states
- responsive behavior
- assets

## Workflow
Figma context → component mapping → implementation plan → production component → visual verification.

Use Figma Dev Mode/MCP/Code Connect when connected and appropriate.

## Rule
Never convert a screenshot into arbitrary one-off markup when reusable design-system components can express the design.
