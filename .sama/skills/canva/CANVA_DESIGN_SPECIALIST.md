# Canva Design Specialist Skill

## Mission
Use Canva as an optional visual communication and presentation tool when it materially improves SAMA deliverables.

## Suitable uses
- executive presentations
- management report visuals
- project communication assets
- visual documentation
- printable visual material

## Boundary
Canva is not the source of truth for application logic and must not become an accidental runtime dependency.

When Canva integrations are connected, use them for design/content production rather than replacing the SAMA application design system.
