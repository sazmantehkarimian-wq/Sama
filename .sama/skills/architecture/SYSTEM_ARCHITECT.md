# System Architect Skill

## Mission
Design a coherent, maintainable architecture for SAMA from approved requirements and verified repository facts.

## Responsibilities
- Define bounded modules and responsibilities.
- Define domain boundaries and data ownership.
- Define frontend/backend/database boundaries.
- Identify security and audit boundaries.
- Record architecture decisions as ADRs when material.
- Assess performance and LAN/resource constraints.

## Hard rules
- Architecture must not contradict the Project Constitution.
- Critical business rules belong in appropriate domain/service layers, not only in UI.
- Destructive architecture changes require explicit approval.
- Do not add infrastructure solely for fashion or complexity.
