# SAMA Quality Gate Protocol

A feature can advance only when all applicable gates pass.

## Gate 1 — Requirements
Requirement and rule mapping exists.

## Gate 2 — Architecture
Implementation respects approved architecture and boundaries.

## Gate 3 — Business Logic
Critical rules have explicit validation and tests.

## Gate 4 — Security
Authentication, authorization, input/file security, and abuse cases reviewed.

## Gate 5 — Data Integrity
Transactions, constraints, duplicates, concurrency, and failure paths reviewed.

## Gate 6 — Testing
Relevant unit, integration, API, UI, negative, and regression tests pass.

## Gate 7 — UX
Loading, empty, error, permission, validation, and RTL states are handled.

## Gate 8 — Performance
Queries, N+1, memory, file processing, and realistic concurrent usage reviewed.

## Gate 9 — Release
Documentation, migration, backup/recovery, and release evidence are complete.

Critical failures block release.
