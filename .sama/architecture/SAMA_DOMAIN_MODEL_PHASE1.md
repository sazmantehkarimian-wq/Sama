# SAMA Domain Model Phase 1

## Objective
Create an independent domain model based on verified SAMA data sources.

## Core domains

- Property (ملک مادر)
- Commercial Space (فضای تجاری)
- Operator
- Contract
- Appraisal
- Auction
- Document
- Approval
- History
- Review Queue

## Design principles

- Preserve historical records.
- Separate current state from history.
- Avoid assumptions not supported by approved sources.
- Keep business rules traceable.

## Status
Draft - awaiting full requirements validation.
