# SAMA Requirement Traceability

This document defines the mandatory traceability chain:

Requirement → Rule → Design → Implementation → Test → Evidence → Release

## Rules

- Every approved requirement receives a stable identifier.
- Every critical business rule must map to one or more tests.
- No implementation is considered complete without traceability for applicable requirements.
- Changes to Version 1.0 requirements require a Change Request.
- Ambiguous requirements must be flagged rather than guessed.

## Status values

- DISCOVERED
- ANALYZED
- APPROVED
- IMPLEMENTED
- TESTED
- VERIFIED
- BLOCKED
- CHANGED
